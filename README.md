# 🎬 StreamMaster

O **StreamMaster** é uma plataforma web responsiva de catálogo e informações sobre filmes, séries e lançamentos. O projeto foi desenvolvido com foco em organização modular, responsividade, manipulação dinâmica de dados e experiência moderna de interface.

---
## 🌐 Live Demo

*Acesse o projeto online: https://tayanne1.github.io/streammaster-platform/

---
## 🚀 Funcionalidades

* Catálogo de filmes e séries
* Navegação dinâmica entre páginas
* Página de detalhes inteligente (`info.html`)
* Sistema de busca integrado
* Layout responsivo com CSS Grid
* Seção “Em Breve” com efeitos visuais
* Sistema de listas salvas no navegador
* Estrutura modular em JavaScript Vanilla
* Design Mobile-First

---

## 🛠️ Tecnologias Utilizadas
